# Kurobi Kitchen — Craft Ramen, Bao & Wood-Fired Small Plates

A restaurant menu, bowl customizer, and ordering web application featuring a **Cross-Platform Adaptive Drawer** built using **100% Native Web APIs** (`<dialog>`, `PointerEvent`, `matchMedia`, and `visualViewport`).

## Adaptive Presentation

- **Desktop (`>= 768px`)**: Clicking any dish card, **Your Order**, or **Book a Table** presents a centered modal dialog with outside backdrop click and `Escape` key dismissal.
- **Mobile (`< 768px`)**: Slides up from the bottom as an interactive bottom sheet with 1:1 pointer tracking, velocity-based flick dismissal, upward rubber-band overscroll resistance, snap points, and nested scroll-to-drag handoff.
