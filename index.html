How the Cross-Platform Drawer Works

Built from scratch using 100% native Web APIs without React, Vue, jQuery, Tailwind, or animation libraries.

01

Adaptive Breakpoint Engine (matchMedia + CSS)

Uses CSS media queries (@media (min-width: 768px)) paired with window.matchMedia('(min-width: 768px)') event listeners. At ≥768px, the container centers the surface as a modal dialog and disables vertical drag gestures. Below 768px, it docks to the bottom edge as an interactive sheet with a grab handle and snap points.

02

Unified Pointer Gesture & Velocity Physics

Tracks gestures via native pointerdown, pointermove, and pointerup events with setPointerCapture. A sliding 80ms sample ring buffer computes instantaneous flick velocity (px/ms). Releasing with velocity > 0.45 px/ms or dragging past 35% of sheet height dismisses the sheet; pulling above the top limit applies hyperbolic rubber-band damping.

03

Nested Scroll-to-Drag Handoff

When dragging inside the scrollable content area on mobile, the drawer inspects bodyEl.scrollTop. If scrollTop > 0, native content scrolling runs uninterrupted. Once scrollTop === 0 and the user pulls downward (ΔY > 0), control seamlessly hands off to translating the bottom sheet without triggering browser pull-to-refresh.

04

Native <dialog>, Safe Areas & visualViewport

Built on the native HTML5 <dialog> element (showModal()) for top-layer promotion, focus trapping, and Escape key interception. Uses 100dvh, env(safe-area-inset-bottom) for iPhone home indicators, and window.visualViewport listeners so mobile on-screen keyboards never obscure focused inputs.
